# Contact uS

This endpoint allows you to add a new contact for an end user.

## Request Body

- `fullname` (text): The full name of the contact person.
- `email` (text): The email address of the contact person.
- `message` (text): The message or query from the contact person.
- `topic` (text): The topic or subject of the message.

## Response

```
{
    "message": "Email is sent successfully."
}
```
